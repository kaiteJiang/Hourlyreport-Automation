# 同事使用说明

内部版同步日期：2026-07-29（v2026.7.29.116）

## 最简单的使用方式

1. 双击管理员提供的 `Hourlyreport_automation_setup_v2026.7.29.116.exe`。
2. 按安装向导选择安装目录；安装完成后从桌面快捷方式启动。
3. 第一次启动会自动检查环境；缺少运行环境时会显示进度并下载隔离的项目专用 Python 3.14.5 与依赖。电脑已有的 Python 不会被使用或修改，无需卸载。
4. 在“系统”菜单中导入管理员提供的授权配置。
5. 选择项目、小时报时段或日报日期后执行；批量处理可切换“多项目”，最多选择 3 个。

GUI 成功完成小时报或日报后会自动打开项目 Excel。多项目会并行读取百度 API，再按选择顺序逐个安全写入，全部结束后统一打开成功项目的 Excel。

多项目模式不使用浏览器降级。某个项目 API 失败时会跳过并继续其他项目；点击停止时，当前项目继续完成，从下一个项目开始停止。

## 窗口与托盘

- 控制台打开时，Windows 任务栏会显示程序小图标。
- 点击控制台右上角 `X` 只会隐藏窗口，程序、托盘和正在执行的任务不会退出。
- 左键单击任务栏通知区域的托盘图标，可以重新打开控制台。
- 真正退出程序只能使用托盘图标右键菜单中的“退出程序”，或控制台“系统配置”中的“退出程序”。

## 在线更新

程序每次启动会静默检查新版本。发现新版时标题栏显示“更新”；点击后持续显示下载百分比，完成后点击“重启”。更新窗口出现后客户端才会退出，安装完成会自动重启。更新不会覆盖本机账号密码、Excel 路径和运行数据。

## 当前项目

正式项目共九个：昆明牛、南京牛、宁波牛、长沙牛、沈阳牛、青岛白、深圳白、南京白、沈阳白。沈阳牛、沈阳白为双百度来源项目。

## 需要人工准备

- 所有正式项目默认使用快商通本地 API；回环服务仅在 API 模式下随 GUI 自动启动。支持 Electron `OnlineWebCS.exe` / `OnlineWebCSNew.exe` 与旧 Java/JCEF `OnlineCS.exe`，所需项目对应的快商通客户端必须保持运行。
- 同一台电脑可以登录多个快商通账号；程序按全局唯一推广 ID 自动绑定项目，存在歧义时不会猜测。
- 只有显式切换到“人工导出对话”后，程序才使用 30 分钟内的最新导出文件。
- 执行前关闭正在打开的目标 Excel/WPS 文件。

本地 API 仅监听 `127.0.0.1`，不会向局域网开放。程序会自动发现 Electron 的 `%LOCALAPPDATA%\OnlineWebCSNew`，以及旧客户端“文档”下的 `KuaiShangDataNew`。自动发现失败、安装位置变化或更换客户端后，在 `系统 > 快商通模式` 依次选择“选择快商通程序目录”“选择快商通数据目录”，或点击“重新扫描快商通”；请选择目录，不要选择或复制数据库文件、登录令牌。

## 商务通 API 模式

实时日志右上角显示 `● KST  ● 实时`：

- KST 绿灯：本地 API 已就绪。
- KST 灰灯：API 未启动或暂不可用，程序会自动重试。
- `● KST` 只显示 API 是否运行，不能点击切换。

API 模式下不需要手动导出商务通文件。若某项目 API 暂时不可用、客户端未运行、账号未登录、程序目录或数据目录无效、数据库不兼容、端口被占用或推广 ID 映射不唯一，该项目商务通指标按 0 继续，百度数据照常处理，并且不会偷偷读取旧导出。系统按 `5 秒 → 15 秒 → 30 秒 → 60 秒` 退避重试；同一原因仅首次、原因变化和每 5 分钟状态提醒写入实时日志。需要应急恢复旧流程时，选择 `系统 > 快商通模式 > 人工导出对话`；该开关对单项目和多项目全局生效，且人工导出模式不会启动或重试本地 API。

## 配置位置

- 项目与 Excel 路径：`configs/projects/*.json`
- 当前默认项目：`configs/app_config.json`
- 百度账号密码：`secrets/secrets.json`

普通同事优先使用 GUI 顶部“系统”，无需手工翻找文件。

## 导入授权配置

管理员完成统一账号和 API 授权后，会提供一个 `.baidu-secrets` 配置包：

1. 打开 GUI 顶部“系统”。
2. 点击“导入授权配置”。
3. 选择管理员提供的配置包。

程序会自动写入正确位置并立即运行项目配置检查。导入失败时会显示具体原因，可按提示重新选择文件。该操作会完整替换本机账号授权配置，但覆盖前会在后台自动保存原配置备份。

云端 Token 模式需要配置包中的独立 HMAC 客户端配置。程序在线更新和安装器不会携带这项敏感配置：

- 7 月 22 日云端模式上线前已经安装的电脑，更新程序后仍需重新导入一次管理员最新配置包。
- 预检提示“云端 Token 配置未就绪，请导入管理员最新授权配置”时，不要反复重跑，直接联系管理员取得当前配置包。
- 导入后可运行“百度 API 就绪检查”；该检查只读百度数据，不启动 Chrome，也不读写业务 Excel。
- 单项目在 Excel 写入前点击“停止”会立即终止当前任务；多项目仍会完成当前项目，再停止后续队列。

## 日志记录

- 控制台实时日志使用快速逐字显示，输出较多时会自动提速。
- 全部日志会永久追加到安装目录的 `logs/gui_history.log`，切换任务或关闭窗口不会删除历史记录。

配置包是包含账号密码、OAuth Token 和 HMAC 客户端配置的明文敏感文件，仅限公司内部使用，不得上传 GitHub、公开网盘或转发给无关人员。

## 安全说明

- 每次写 Excel 前自动备份。
- 不重建 Excel，不修改无关 sheet、公式区、汇总区和截图区。
- 程序发布包不包含本机凭据；管理员另行提供的 `.baidu-secrets` 配置包不得发给外部或上传到公开网盘、代码仓库。
- 遇到验证码、滑块或安全验证时，按界面提示人工处理。
