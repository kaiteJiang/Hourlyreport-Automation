# 蚁之力 · 竞价数据自动化 v2026.7.31.118

## 稳定性与兼容性升级

本次更新聚焦同事电脑上出现的快商通本地 API 无法启动、身份无法映射、重新扫描失效，以及百度 API 长时间无响应等问题。保持既有业务流程与数据口径不变，以最小范围修补增强多版本客户端适配和故障可诊断性。

## 快商通双版本适配

- 人工选择的快商通数据目录现在会真正参与后续发现，兼容 Electron `OnlineWebCSNew` 与旧 Java/JCEF `KuaiShangDataNew` 目录结构。
- 指定旧版目录后仍会自动发现新版客户端；新旧客户端可并存，某一路未运行不会再屏蔽另一路的健康身份。
- 旧版 `7.03.17` 数据库兼容根历史库、月归档和编号消息分片；不完整的新登录空壳身份只输出诊断，不阻断其他可用身份。
- 单个 Electron 身份数据库异常时，不再拖累其他可用身份；程序会继续核验其余只读数据库。
- 数据库暂时无法提供推广 ID 时，可从目标日期、具有服务器自动同步凭证的日志中严格匹配正式项目 ID，不猜测、不跨项目串读。
- 本地 API 健康状态现在以“当前所选项目能否安全绑定”为准，避免其他项目已就绪造成误判。

## 恢复入口与界面反馈

- “重新扫描快商通”始终可点击；在人工导出模式下点击会明确切回本地 API 并执行扫描。
- 路径异常仅在设置区提示，不再自动弹出可能隐藏在其他窗口后的目录选择框。
- 百度数据阶段连续 45 秒没有新输出时，界面会明确提示任务仍在运行，停止按钮仍可使用，避免误以为客户端已经卡死。

## 脱敏诊断增强

- 快商通失败按身份映射、数据库不兼容、数据库忙或读取超时、客户端未运行、目录无效等安全类别写入报告。
- 百度 API 失败报告增加来源、授权 profile 与脱敏后的失败摘要，双授权项目可直接区分是哪一路失败。
- 日志和报告继续不写入 Token、密钥、真实推广 ID 或原始异常详情。

## 升级建议

- v112–v117 用户建议升级至 v118。
- 已安装客户端使用 `Hourlyreport_automation_v2026.7.31.118.zip` 在线更新。
- 新电脑或需要完整修复安装时使用 `Hourlyreport_automation_setup_v2026.7.31.118.exe`。
