# 蚁之力 · 竞价数据自动化 v2026.8.6.121

## 商务通导出解析：兼容「对话关键词」列

部分项目（南京牛等）的商务通导出文件使用「对话关键词」列而非「搜索关键词」，此前词类占比、日报在人工导出模式下会报「未识别到搜索关键词」导致整单失败。本版在搜索词识别中加入「对话关键词」别名，两种列名均可正确解析。

- 词类占比商务通侧：导出文件列名「搜索关键词」或「对话关键词」均可命中银屑病/牛皮癣关键词筛选。
- 日报/小时报导出模式同步受益。
- 商务通本地 API 模式（昆明牛等）读取本地数据库，字段名由程序统一，不受影响。

## 全局商务通模式默认「人工导出」

系统菜单全局商务通模式（`app_config.kst_data_source`）默认值调整为「人工导出」，新装机开箱即为导出模式，与当前生产环境一致；本机按需切换「API」模式。
