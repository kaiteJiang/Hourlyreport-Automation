# v2026.7.28.115 更新说明

## 商务通启动加速

- 本地 API 未就绪时的后台探测间隔由 15 秒缩短为 5 秒，减少启动后的等待时间。
- 同一登录身份可从历史日志恢复服务端接口 URL，避免当天日志没有重复记录 URL 时长时间等待。
- 历史日志只恢复接口 URL；公共查询参数、请求头和 Token 等当天认证材料不会跨日复用。

## 日报读取性能

- 13 条会话按不同会话最多四路并发读取，单个会话内部仍保持原有顺序。
- 匿名测量中，13 条会话对应的 26 次请求正常约 1.96 秒完成。
- 实际耗时仍受外部网络和上游服务影响，偶发请求仍可能出现长尾。

## 认证与失败安全

- 当天认证材料缺失或不完整时，对应身份不会进入可用注册表，KST 状态保持灰色。
- 单会话内部调用顺序不变；任一会话失败或返回不完整时，仍丢弃整批商务通临时结果。
- 项目未绑定、映射歧义、接口失败或结果不完整时，商务通指标继续按 0 处理，百度数据照常处理，不读取旧导出文件。
