# v2026.7.27.113 更新说明

## 重点更新

- 小时报、日报默认通过快商通本地只读 API 获取对话数据，不再要求每次人工导出。
- 支持一台电脑同时登录多个快商通身份，按推广 ID 将身份严格绑定到唯一项目，避免跨项目读取。
- “系统 → 快商通模式”可在“API 自动获取”和“人工导出对话”之间全局切换。
- 实时日志区新增 KST 状态指示；API 未就绪时自动重试。
- API 不可用、项目未绑定、映射歧义或结果不完整时，该项目快商通指标按 0 继续，百度数据照常处理；不会偷偷读取旧导出文件。

## 性能与稳定性

- 日志改为增量读取，避免后台反复扫描大体积历史日志。
- 健康状态下完整身份刷新降为每 5 分钟一次，相同语义输入在 60 秒内复用运行时。
- 修复日志截断、同名替换和带空格 JSON 格式可能造成的漏数。
- 日志缓存和项目运行时缓存增加容量上限，避免长时间运行或多日期查询持续占用内存。
- SQLite WAL/SHM 变化会立即使运行时缓存失效。
- 小时报与日报并发查询共享一次会话读取，避免重复请求快商通接口。

## 数据与安全边界

- 只统计具有服务器自动推送或启动自动同步凭证的会话，人工历史查询不会混入。
- API 最终推广 ID 必须属于当前项目；发现越界会话时整次查询失败并按既定规则降级，不再静默少算。
- 日期、时段和项目 ID 必须与请求完全一致。
- 本地 API 仅监听 `127.0.0.1:18766`，首次启动自动生成本机令牌到不参与发布的 `runtime/`；健康检查与数据接口均需认证。
- 默认配置不再包含开发机安装路径或真实快商通 identity。

## 兼容性

- 原人工导出小时报、日报流程保留，可随时从系统菜单切回。
- 不改变百度 API/浏览器策略、Excel 备份与写入边界。
