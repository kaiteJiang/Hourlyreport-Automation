# 蚁之力 · 竞价数据自动化 v2026.7.29.116

## 双代际本地数据引擎

- 快商通本地只读 API 支持两类客户端：Electron `OnlineWebCS.exe` / `OnlineWebCSNew.exe`，以及旧 Java/JCEF `OnlineCS.exe`。
- 自动发现 Electron 的 `%LOCALAPPDATA%\OnlineWebCSNew` 与旧客户端 Windows“文档”目录下的 `KuaiShangDataNew`；客户端必须保持运行，程序不会启动、控制或写入快商通客户端。
- 自动发现失败时，可在 `系统 > 快商通模式` 选择程序目录、数据目录，或重新扫描快商通；选择的是目录，不是单个数据库文件。

## 可诊断的失败边界

- 认证配置、程序目录、数据目录、客户端未运行、数据库结构、身份映射、端口占用和启动失败均以脱敏类别显示。
- 未就绪时按 `5 秒 → 15 秒 → 30 秒 → 60 秒` 退避；相同原因仅首次、原因变化和每 5 分钟状态提醒写实时日志，成功后重置。
- API 不可用、项目未绑定、推广 ID 映射歧义或结果不完整时，快商通指标按 0 继续，百度数据照常处理，不隐式读取旧导出。
- 切换到 `系统 > 快商通模式 > 人工导出对话` 后，继续使用人工导出流程，不启动或重试本地 API。

## 发布边界

- 所有发布包均排除 `runtime/`、SQLite 主库（`.db`、`.cdb`、`.pdb`、`.sqlite`、`.sqlite3`）及 WAL/SHM/journal 旁路文件，避免本机运行态和数据库进入交付物。
- `logs/`、`reports/`、`backups/`、`kst_exports/` 等运行时目录连同占位文件均不进入在线更新包或完整安装器；首次安装仍保留默认项目配置与脱敏示例，不携带真实授权。
- 本版本的 Electron 既有读取链路与旧 Java/JCEF 适配器均有自动化结构测试；真实业务数据口径仍需在对应客户端与账号环境中由业务同事验收。
