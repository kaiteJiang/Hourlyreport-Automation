# v2026.7.27.114 更新说明

## 发布包精简

- 修复快商通本地 API 静态引用手工 Excel/CSV 解析模块，导致 GUI EXE误打包 `pandas`、`numpy` 和 OpenBLAS 的问题。

- 移除已经被 GUI、菜单和 HERMES 固定入口替代的旧 BAT。

- 本机 Claude 设置不再由 GitHub 跟踪，但本地文件继续保留。
- 清理旧发布包、PyInstaller 缓存、日志、报告、诊断和临时文件。

## 保留与兼容

- 保留 `browser_profile/`，不会清除百度登录状态。
- 保留 `backups/`，不会删除 Excel 或 Token 安全备份。
- 保留 `.venv/`、`secrets/`、`configs/` 和 `runtime/`。
- 不改变百度 API/浏览器降级策略、快商通统计口径和 Excel 安全写入规则。
