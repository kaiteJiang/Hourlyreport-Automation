# 蚁之力 · 竞价数据自动化 v2026.7.29.117

## Electron 动态数据库兼容修复

- 修复快商通 Electron 客户端持续写入 `VISITOR*.db` 或 WAL 旁路文件时，被 v116 错误判定为“数据库忙或读取超时”的回归。
- 身份注册现在区分客户端代际：Electron 允许同一路径数据库正常动态写入，旧版 Java/JCEF 继续执行完整严格指纹保护。
- Electron 安装根、登录身份或数据库路径集合发生变化时仍会安全失效并要求重新扫描，不降低身份隔离边界。
- 数据库内容变化会使运行态缓存重建，不会继续复用变化前的业务数据。

## 人工路径恢复入口

- “系统”内嵌快商通设置区直接增加“选择快商通程序目录”“选择快商通数据目录”和“重新扫描快商通”。
- 自动发现明确返回程序目录或数据目录无效时，每次启动最多弹出一次对应目录选择窗口；用户取消后不会循环弹窗。
- 数据库、身份映射和客户端未运行等非路径错误不会误触发目录窗口。

## 安全边界

- 本地 API 继续只绑定 `127.0.0.1:18766`，数据库访问保持只读。
- 在线更新继续保留用户的 `configs/`、`secrets/`、日志、报告、备份、人工导出和运行时设置。
- 发布包继续排除真实授权、运行数据、SQLite 数据库及 WAL/SHM/journal 旁路文件。

## 升级建议

- v116 用户建议立即升级 v117。
- 已有客户端使用 `Hourlyreport_automation_v2026.7.29.117.zip` 在线更新。
- 新电脑或需要完整修复安装时使用 `Hourlyreport_automation_setup_v2026.7.29.117.exe`。
