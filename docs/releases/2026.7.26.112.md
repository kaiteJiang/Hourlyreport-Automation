# v2026.7.26.112 更新说明

发布日期：2026-07-26

## 本次修复

- 修复旧客户端仅有本地 OAuth Token、缺少云端 `token_url` 时仍被误判为 API 可用的问题。
- 百度 API 生产通道不再静默退回旧的本地 Token 刷新链路；云端配置缺失时快速给出明确原因，并按既有规则进入浏览器降级。
- 云端 API 就绪检查改为验证 HMAC 网关、HTTPS Token 端点、应用 `app_id` 及项目授权映射；检查结果只包含安全布尔值，不输出 Token 或密钥。
- 修复单项目卡在“获取百度数据”时点击停止无效的问题。确认 Excel 尚未开始写入后，程序会立即终止当前任务进程。
- 多项目停止规则保持不变：当前项目继续完成，只停止后续排队项目。

## 重要配置说明

云端 Token 所需的 HMAC 客户端配置包含在管理员导出的 `.baidu-secrets` 授权配置包中。
在线更新包和完整安装器不会携带真实 HMAC 密钥。

- 7 月 22 日云端模式上线前已经安装的电脑，即使程序升级到本版本，也必须重新导入一次管理员最新授权配置。
- 预检提示“云端 Token 配置未就绪”时，不要反复重跑；应在 GUI“系统 → 导入授权配置”中导入当前配置包。
- 不要手工复制单个 Token 字段，也不要把 `.baidu-secrets` 放入发布包、GitHub 或公开网盘。

## 验证结果

- 云端 Token/预检/停止相关回归测试通过。
- 完整基础测试通过。

- 独立代码审查确认 Excel 停止边界、多项目规则和敏感信息边界均保持。
- 在线更新包与完整安装器均验证不包含用户配置、真实凭据、日志、报告、备份或诊断数据。
