# 蚁之力 · 竞价数据自动化 v2026.8.4.119

## 新增：词类占比报表

日报模块新增"词类占比"按钮（替换原"默认昨天"），统计银屑病/牛皮癣两类搜索词的百度侧与商务通侧数据，写入与竞价报表同目录的 `【项目名】{年份}词类占比数据.xlsx`：

- **点击、消费**：从百度搜索词报告（openBD API）按搜索词列筛选含"银屑病"或"牛皮癣"的行，跨账户加总。
- **有效对话、有效转潜**：从商务通访客对话按搜索关键词筛选，对话标签含"有效"计有效对话、含"转潜-有效"计有效转潜。
- **到诊**：不填写。

2026-08-03 实测：命中搜索词 67 条、点击 143、消费 832.16，商务通对话 11 条匹配、有效对话 1、有效转潜 1，与手工统计完全一致。

## 稳定性修复

- 快商通日志白名单纳入实时新访客推送（msgType 9）与访客信息推送（msgType 452），避免这些对话在自动来源采集阶段被过滤掉。
- 云端访客记录尚未就绪导致 `visitorInfo/load` 返回空时，小时报/日报回退使用本地候选数据，不再把单条对话的富化失败拖成整份"商务通 API 不可用"并全按 0 处理。

## 发布包修正
