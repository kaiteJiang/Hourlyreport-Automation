# 蚁之力 · 竞价数据自动化 v2026.8.5.120

## 词类占比：全面适配人工导出与多来源项目

v119 的"词类占比"报表在本版补齐了跨项目适配，所有项目（含多来源项目）均可使用：

- **商务通人工导出模式**：词类占比与日报共用同一份导出的商务通对话表。把商务通文件导出到项目指定目录后，词类占比直接读取解析，不再依赖本机商务通 API 启动，同事电脑也能正常出数。
- **百度侧多来源聚合**：沈阳白、沈阳牛等多来源项目（`baidu_sources` 各自带 API 授权账户）逐来源拉取搜索词报告并聚合；单来源项目自动回退顶层 API 授权。凡有百度 API 授权的项目，词类占比百度侧均可用；无授权则明确报错。
- **按项目病种区分关键词**：项目名含"白"（白癜风项目）筛选"白癜风"，其余项目筛选"银屑病/牛皮癣"。
- **多项目模式**：支持最多 3 个项目同时生成词类占比报表，百度 API 并行拉取、各项目 Excel 串行写入，避免并发写表冲突。
- **匹配口径修正**：商务通侧只按搜索关键词匹配（不再误匹配推广词/创意词），避免把不相干对话计入。

## 修复

- 修复词类占比 0 有效：删除聚合函数重复调用导致的关键词覆盖。
- 修复多项目模式下打开错误 Excel：词类占比现打开词类报表而非竞价报表。
- 修复词类占比按钮无反应：补全命令构建函数导入。
- 修复商务通导出模式日期过滤：改用正确的日期过滤行，导出文件不再取到被排除行。
- runner 忙交互优化：点击时改为日志提示而非弹窗；任务守卫改为重置后启动；旧任务延迟重启消除竞态，避免连续点击卡死。
