# 商务通 API GUI 托管与来源切换设计

## 目标

让昆明牛小时报在 GUI 运行期间自动获得商务通本地 API 服务，并在实时日志区域右上角显示准确、可理解的服务状态。用户无需手工启动 API；API 不可用时小时报仍可只使用百度数据完成。

## 最终界面

实时日志框右上角原来的 `● 已就绪` 替换为：

```text
● KST  ● 实时
```

- 第一个圆点表示商务通本地 API：
  - 绿色：API 已启动并可响应健康检查；
  - 灰色：API 未启动、正在重试或启动失败。
- 第二个圆点保持绿色，表示实时日志正在工作。
- 悬停 `● KST` 显示当前状态、地址和最近一次错误。
- 点击 `● KST` 打开昆明牛商务通来源菜单：
  - `API 自动获取`
  - `人工导出`
- 菜单选择写入 `configs/projects/kunming_niu.json` 的 `kst.data_source`，下次启动继续使用。

## API 生命周期

新增 GUI 专用 `KstApiManager`：

1. GUI 完成界面创建后异步启动管理器，不能阻塞主线程。
2. 管理器先检查 `127.0.0.1:18766/health`：
   - 如果已有兼容服务，直接复用并点亮 KST；
   - 如果端口空闲，GUI 在后台线程内启动现有 `ThreadingHTTPServer`；
   - 如果端口被非商务通服务占用，KST 保持灰色并记录原因。
3. 商务通客户端未启动、未登录或路径暂时不可用时，管理器每 15 秒重试。
4. GUI 隐藏到托盘不停止服务。
5. 用户真正退出 GUI 时：
   - GUI 自己启动的服务执行 `shutdown`、`server_close` 并等待线程退出；
   - 启动前已存在的外部兼容服务只复用，不由 GUI 关闭。
6. 状态变化通过 Qt Signal 回到主线程，更新 KST 圆点、提示文字和实时日志。

服务继续只监听 `127.0.0.1`，认证令牌只从环境变量读取。

## 小时报数据来源

### API 自动获取

`kst.data_source=local_api` 时，小时报步骤 2 调用 GUI 托管的本地 API。

- 成功：使用真实商务通统计。
- API 连接失败、健康检查失败、客户端未登录或响应不完整：
  - 商务通各账户指标写 0；
  - 解析报告标记来源为 `kst_local_api_unavailable_zero`；
  - 报告和实时日志保留明确警告；
  - 继续合并百度数据并允许正常写入 Excel；
  - 不自动读取旧人工导出，避免重复或使用过期数据。

### 人工导出

`kst.data_source=export` 时保持现有行为，从人工导出的 Excel/CSV 读取商务通数据。

API 与人工模式始终互斥，不在一次小时报中混合。

## 临时与最终配置

- 开发期间昆明牛暂时保持 `data_source=export`，不影响当前小时报。
- API GUI 托管、状态显示和降级逻辑全部验证通过后，再把昆明牛切回 `data_source=local_api`。
- 即使最终默认 API，用户仍可点击 `● KST` 随时切回人工导出。

## 错误与安全行为

- KST 灰灯只表示 API 不可用，不阻断 GUI 和其他项目。
- 昆明牛 API 模式在灰灯状态下仍允许启动小时报，商务通按 0。
- 人工模式不要求 API 可用。
- 多项目任务包含昆明牛时，API 不可用只使昆明牛商务通指标为 0，不阻断其他项目。
- 不修改商务通数据库、安装文件或进程内存。
- GUI 日志不得输出 `clientToken`、Cookie、完整请求头、聊天正文或访客个人信息。

## 组件边界

### `gui/kst_api_manager.py`

- 负责服务探测、启动、重试、停止和状态信号。
- 不直接操作界面控件。
- 暴露 `start()`、`stop()`、`is_ready()`、`status_detail()`。

### `gui/main_window.py`

- 创建 `● KST  ● 实时` 控件。
- 订阅管理器状态并更新样式、提示和日志。
- 提供 API/人工来源菜单并刷新选中状态。
- 在真正退出应用前停止管理器。

### `modules/kst_local/source.py`

- 负责小时报通过本地 API 取数。
- 根据 `allow_zero_on_unavailable` 生成结构兼容的零商务通报告。

### `modules/project_config.py`

- 提供读取和保存单项目商务通来源的接口。
- 只允许 `local_api` 与 `export` 两个值。

## 验收标准

1. GUI 启动后无需手工命令，API 自动启动。
2. GUI 真正退出后，自有 API 端口被释放。
3. 已存在兼容 API 时能够复用，退出 GUI 不误杀外部服务。
4. 右上角准确显示 `● KST  ● 实时`，不再显示“已就绪”。
5. API 成功时 KST 圆点绿色；失败时灰色并有可读提示。
6. 点击 KST 可在 API 与人工导出间切换，重启后保持。
7. API 模式成功时，2026-07-26 昆明牛保持 26 条、14/1/11、五项指标与人工导出完全一致。
8. API 不可用时，昆明牛商务通指标为 0，百度数据流程可以继续。
9. 人工模式仍能执行现有导出解析。
10. 自动化测试和 GUI 离屏视觉检查通过；不运行正式 Excel 写入。
