# 蚁之力内部汇报宣传片设计

## 目标

制作一支约 60 秒、16:9 横屏、面向公司内部领导与老板同事的产品介绍视频。视频要让观众在一分钟内理解：蚁之力把百度竞价数据、快商通数据、校验合并、Excel 安全写入和小时报/日报流程串成了可追溯的自动化链路。

## 创作模式

采用 `video-shotcraft` 自主自由创作流程。用户已明确时长、受众、真人出镜、语言、配音方向和制作 skill；缺省的视觉方向、镜头卡、动效参数、SFX 和素材取舍由 Agent 决策并记录。

## 受众与语气

- 受众：公司内部领导、老板、同事。
- 语气：稳健、清楚、可信，不使用外部客户案例或夸张 ROI 承诺。
- 核心叙事：从“人工抄数与反复核对”转向“自动读取、校验、合并、备份、写入、复核”。
- 真人出镜：使用公共数字人作为主持人口播，不采集或生成用户本人肖像。

## 视觉方向

选择“专业信赖 + 产品发布会收束”方向：

- 背景：`#F7FAFF` 亮场为主，进入安全写入段时使用深蓝 `#0B1B31` 形成重点对比。
- 强调色：蓝 `#3B82F6` 表示数据流与系统状态；橙红 `#F05A3C` 表示动作完成和品牌强调。
- 字体：Microsoft YaHei / 系统无衬线，标题有效字高不低于 56px，辅助说明不低于 32px。
- 动效 tokens：专业信赖预设，约 21f 入场，ease-out，无无意义弹跳；发布会合影段只在落定处使用一次轻微过冲。
- 运镜：产品 GUI 使用真实截图、2.5D PageCam 和稳定推近；不使用手持抖动；信息密集画面保持正视。
- 光效：只给主角卡片和最终品牌合影各一次单点光效，全部裁进圆角边界，不做逐卡闪烁。

## 数据与素材安全

- 真实产品画面来自已有 GUI 截图；原始内部日志路径、账号、凭据、客户名和业务数据不进入最终视频。
- 用抽象状态条、虚构状态值和脱敏截图覆盖敏感区域。
- 不运行真实 `run` / `run-daily`，不写目标 Excel，不修改生产配置和 secrets。
- 主持人和配音均不使用用户本人身份素材；配音沿用上一版 HeyGen 中文音色风格，按新脚本重新生成。

## 1 分钟分镜与旁白

| # | 时间 | 镜头 | 关键动效 |
|---|---:|---|---|
| 1 | 0–8s | 真人主持人面对镜头提出问题：竞价数据还在人工抄表、反复核对吗？ | 主持人轻推近，右侧出现产品字标与一张数据卡；稳定、完整动作弧 |
| 2 | 8–15s | 问题拆解：数据源分散、时间紧、错误难追溯 | `spotlight-hero-card` 语法：聚光锁定“数据入口”卡，真实 GUI 作为背景 |
| 3 | 15–25s | 蚁之力自动读取百度与快商通数据 | 真实桌面 GUI 进入 PageCam，数据源卡从两侧嵌入真实槽位；字幕同步讲解 |
| 4 | 25–35s | 自动完成字段识别、校验和合并 | `ai-stream-response` 语法：先落结论，再逐条汇入“已读取 / 已校验 / 已合并 / 已复核”状态行 |
| 5 | 35–45s | Excel 写入前备份、动态识别目标区域、写入后复核 | `row-embed` 语法：安全写入、备份、目标区域、复核四行依次嵌入状态面板；深蓝安全段落 |
| 6 | 45–53s | 小时报、日报、多项目统一处理 | 三张能力卡错峰进入，最后静止 0.5s；文案具体化为“小时报 / 日报 / 多项目” |
| 7 | 53–60s | 真人主持人回到画面，给出内部汇报式结论 | `outro-group-photo-launch` 语法：已展示的 GUI、数据流、盾牌和报表卡从四方合影，品牌字标落定并保持 ≥1s |

## 旁白脚本

“各位领导、同事，大家好。竞价数据还在人工抄表、反复核对吗？当数据源越来越多，真正耗费时间的，往往不是查看，而是确认每一个数字都来自正确的位置。蚁之力，把百度和快商通的数据读取、字段识别、校验与合并，串成一条自动化流程。系统先检查数据是否完整，再把不同来源的结果统一到项目口径；每一步都有状态反馈，异常也能留下清晰的追踪线索。进入 Excel 前，流程会先备份原文件，动态识别目标区域，并在写入完成后再次复核，保护公式区和非目标内容。无论是小时报、日报，还是多个项目，重复工作都可以按统一规则稳定执行。蚁之力，让数据从采集到报告，更快、更稳，也更容易复盘。谢谢大家。”

## 音频

- 主旁白：沿用上一版 HeyGen 中文公共音色 `BOB - Voice 1` 的风格，重新生成本版脚本。
- BGM：从 shotcraft 音频资产中选择强节奏但克制的 tech-house 底，混音时给旁白和 SFX 留空间；同时输出带 BGM 与无 BGM 版本。
- SFX：按相对镜头起点钉帧，采用 `transition-soft`、`whoosh-big`、`click-camera`、`riser-cine`、`impact-deep-whoosh`、`sparkle`，长样本显式截断。
